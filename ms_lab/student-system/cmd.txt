PostgreSQL can be run using:
docker run -d \
  --name student-db \
  -e POSTGRES_DB=studentdb \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=student123 \
  -p 5432:5432 \
  postgres:16-alpine



kubectl version --client
kubectl get nodes

Build images:
docker build -t student-frontend:1.0 ./frontend
docker build -t student-backend:1.0 ./backend-flask

Deploy the database:
kubectl apply -f kubernetes/database.yaml

Deploy the backend:
kubectl apply -f kubernetes/backend.yaml

Deploy the frontend:
kubectl apply -f kubernetes/frontend.yaml

Create the Services:
kubectl apply -f kubernetes/services.yaml

Check the applications:
kubectl get deployments
kubectl get pods
kubectl get services
kubectl get pvc

Troubleshooting commands:
kubectl describe pod POD_NAME
kubectl logs POD_NAME
kubectl get events

Stop and remove Kubernetes resources:
kubectl delete -f kubernetes/services.yaml
kubectl delete -f kubernetes/frontend.yaml
kubectl delete -f kubernetes/backend.yaml
kubectl delete -f kubernetes/database.yaml



Build the Node.js backend image with:
docker build -t student-backend:1.0 ./backend-node
