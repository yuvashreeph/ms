
1)Create a network, run 2 containers, and demonstrate communication


Create a Docker network : docker network create my-network

Check: docker network ls

Create first container in that network : 
docker run -d --name container1 --network my-network nginx

Create second container in the same network:
docker run -it --name container2 --network my-network alpine sh

Install ping in alpine (if required):
apk update
apk add iputils

Demonstrate communication:
ping container1

Install curl:
apk add --no-cache curl

curl http://container1

Verify both containers:

docker ps
docker network inspect my-network



2) Pass build-time arguments using --build-arg

Build image by passing argument :
docker build --build-arg APP_VERSION=1.0 .

docker build --build-arg ENVIRONMENT=production -t myapp .

docker run myapp
docker run -it --name mycontainer myapp
